# 2.5 acceptance review packet

Status: frozen local acceptance data; independent scientific review **pending**. Experimental, non-operational. No collision probability is supplied without valid uncertainty inputs.

`horizons-round-1.json` contains 32 distinct off-grid UTC epochs for each of nine playback bodies and eight orbit guides: 544 comparisons. Deterministic stratification includes edge-adjacent intervals and non-midpoint fractions. These samples were not used to choose the original guide cadence. They query the same JPL physical model independently of the tabulated grid, not an independent astronomical model. Request parameters, Horizons headers/kernel identifiers, API signature, response SHA-256 and exact input-table SHA-256 accompany each body. Sun-centered geometric ICRF/ECLIPTIC vectors use km and km/s; Horizons `TIME_TYPE=UT` is retained. Legacy data rounds vectors to six decimal places.

Playback limits remain 100 m position and 0.1 m/s velocity. Guides have a separate 100 km sampled position limit; their velocity errors are reported but not qualified as playback. `node scripts/check-v25-science.mjs 1` reports max/p95 per body. Existing orbit-guide tests cover all monthly playback dates, finite adaptive geometry, 360-degree sweep, real unforced endpoints, exact selected-date anchoring, cache and partial fallback. Wider guides never extend the 2020-01-01–2035-12-31 playback table.

`sgp4-holdouts.json` adds 48 comparisons using MIT python-sgp4 **2.25** (accelerated C++ implementation), WGS72/improved mode, raw TEME km and km/s at explicit minutes from UTC epoch. Six original synthetic OMM cases cover near-Earth, polar/negative BSTAR, MEO, half-day and synchronous resonance, eccentric orbits, leap-day and year boundaries, reverse and fractional offsets. IDs are synthetic and not live objects. Limits: 5 m and 5 mm/s. This is a separate implementation of the same SGP4 theory, not independent physical validation. Published historical reference cases are retained unchanged.

Offline check: `node tests/v25ScientificAcceptance.test.js`. Regeneration is deliberate: `node scripts/python.mjs tools/generate_v25_acceptance.py --round 2` uses serial cached HTTPS requests and refuses to overwrite a round. If a holdout fails, retain it as diagnostic evidence, fix implementation/data, then query a fresh untouched round; never loosen limits to get a pass. Optional SGP4 generation: install `sgp4==2.25` into `runtime/v25-validation-tools`, then run `tools/generate_v25_sgp4.py`; it refuses to overwrite frozen output. Neither generator runs in the app or ordinary tests.

Reviewer tasks: verify time/frame conventions and reference rights, inspect errors and sampling blind spots, reproduce frozen tests, inspect full-guide geometry and interpolation between tested epochs, assess scientific suitability for the proposed use, and sign a dated scope/limitations record. Until that occurs, external approval remains pending. Licensing exclusions are recorded in the [transition inventory](../governance/LICENSING_TRANSITION_V2_5.md).
