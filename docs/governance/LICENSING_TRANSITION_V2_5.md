# Commercial licensing and public source

On 2026-11-08 the owner authorized public GitHub publication of v2.5 under the commercial model and supplied **Jean-Christophe Arcaz / arcazj@gmail.com** as licensor/contact. The repository stays public. This records the owner's decision, not independent legal approval.

The boundary is new owner-controlled material added after public 2.4.0 commit `f7724f5918349fbc972958f53b01732b9ea1bc2f`. [LICENSE](../../LICENSE) and [LICENSE.md](../../LICENSE.md) are identical. The [prior MIT notice](../../licenses/LEGACY_MIT.txt) is retained verbatim; upstream components, provider data, reference fixtures and legacy visual assets are not relicensed as proprietary. GitHub viewing/forking rights remain. Commercial use of new material requires a separate written agreement; no fees, jurisdiction, customer term or SLA are invented here.

| Private materials | Original unpublished work preserved in a verified local Git bundle. Public commits start at v2.4 and omit the private agreement and internal implementation prompt |

Only unpublished history is reconstructed; existing public commits and tags are preserved. The private review package must never be uploaded as a release asset. Public source publication does not certify every historical asset for commercial redistribution.
