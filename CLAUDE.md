# Repository guidance

Use [Contributing](docs/CONTRIBUTING.md), [Testing](docs/TESTING.md), and the [documentation index](docs/README.md).

Run `npm run check` and the suites appropriate to the change. Keep frozen validation bytes intact. Keep runtime state, credentials, private agreements and build outputs out of Git and public artifacts. Preserve legacy workflows and prior MIT grants.

This short file remains at the root for coding-tool discovery. User instructions take precedence over repository guidance.
